Установка пакета
Для начала можно установить инструмент:

SavitskiyES@htb[/htb]$ sudo apt-get update && apt-get -y full-upgrade
SavitskiyES@htb[/htb]$ sudo apt-get install gvm && openvas





Далее, чтобы начать процесс установки, можно выполнить следующую команду:

SavitskiyES@htb[/htb]$ gvm-setup

Это запустит процесс настройки, который займет до 30 минут.


Запуск OpenVas

SavitskiyES@htb[/htb]$ gvm-start



Сканирование OpenVAS

Конфигурация
Перед настройкой сканирования рекомендуется предварительно настроить цели сканирования. Перейдя на Configurationsвкладку и выбрав соответствующий пункт Targets



Чтобы добавить свой собственный объект, щелкните значок, выделенный ниже, и добавьте отдельный целевой объект или список хостов. Вы также можете настроить другие параметры, такие как порты, аутентификация и методы определения доступности хоста. Для этого используется Alive Test опция Scan Config Default OpenVAS, которая задействует компонент NVT Ping Hostиз NVT Family. Подробнее о семействе NVT можно узнать https://docs.greenbone.net/GSM-Manual/gos-22.04/en/scanning.html#creating-a-target .



Примечание:
Как правило, authenticated scanиспользуется пользователь с высокими привилегиями, например root, или Administrator. В зависимости от уровня прав доступа пользователя, если это самый высокий уровень, вы получите максимальный объем информации от хоста относительно имеющихся уязвимостей, поскольку у вас будет полный доступ.



Настройка сканирования
В нескольких конфигурациях сканирования используются семейства сетевых уязвимостей OpenVAS (NVT), которые включают в себя множество различных категорий уязвимостей, таких как уязвимости для Windows, Linux, веб-приложений и т. д. Ниже представлены несколько различных типов семейств:



OpenVAS предлагает различные конфигурации сканирования сети. Мы рекомендуем использовать только указанные ниже, поскольку другие параметры могут привести к сбоям в работе сети:

Base Данная конфигурация сканирования предназначена для получения информации о состоянии хоста и операционной системе. Проверка на наличие уязвимостей в данной конфигурации не производится.
Discovery Данная конфигурация сканирования предназначена для сбора информации о системе. Она определяет службы хоста, оборудование, доступные порты и используемое в системе программное обеспечение. Данная конфигурация сканирования также не проверяет наличие уязвимостей.
Host Discovery Данная конфигурация сканирования проверяет только работоспособность хоста и определяет, какие устройства находятся activeв сети. Она не проверяет наличие уязвимостей. OpenVAS использует команду ping для определения работоспособности хоста.
System Discovery Этот метод сканирования более детально, чем «Обнаружение», перечисляет целевой хост и пытается определить операционную систему и оборудование, связанные с этим хостом.
Full and fast Данная конфигурация рекомендуется OpenVAS как наиболее безопасный вариант и использует интеллектуальные функции для выбора наилучших проверок NVT для хоста (хостов) на основе доступных портов.


После нажатия на кнопку «Отчет» вы сможете просмотреть результаты сканирования, информацию об операционной системе, открытых портах, службах и т.д. на других вкладках отчета.




Для целей отчетности доступны различные форматы экспорта, включая XML, CSV, PDF, ITG и TXT. Если вы решите экспортировать отчет в формате XML, вы сможете использовать различные XML-парсеры для просмотра данных в более удобном для чтения формате.






SavitskiyES@htb[/htb]$ python3 -m openvasreporting -i report-2bf466b5-627d-4659-bea6-1758b43235b1.xml -f xlsx
Эта команда создаст документ(отчет) Excel
