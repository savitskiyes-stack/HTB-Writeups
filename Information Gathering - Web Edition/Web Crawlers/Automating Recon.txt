FinalRecon
FinalReconПредлагает обширный объем разведывательной информации:

Header InformationРаскрывает подробную информацию о сервере, используемых технологиях и потенциальных ошибках в настройках безопасности.
Whois Lookup: Раскрывает данные о регистрации домена, включая информацию о регистранте и контактные данные.
SSL Certificate InformationПроверяет SSL/TLS-сертификат на действительность, издателя и другие важные данные.
Crawler:
HTML, CSS, JavaScript: Извлекает ссылки, ресурсы и потенциальные уязвимости из этих файлов.
Внутренние/внешние ссылки: отображает структуру веб-сайта и определяет связи с другими доменами.
Изображения, robots.txt, sitemap.xml: Собирает информацию о разрешенных/запрещенных путях сканирования и структуре веб-сайта.
Ссылки в JavaScript, Wayback Machine: Раскрывает скрытые ссылки и исторические данные веб-сайтов.
DNS EnumerationВыполняет запросы к более чем 40 типам DNS-записей, включая записи DMARC для оценки безопасности электронной почты.
Subdomain EnumerationИспользует множество источников данных (crt.sh, AnubisDB, ThreatMiner, CertSpotter, Facebook API, VirusTotal API, Shodan API, BeVigil API) для обнаружения поддоменов.
Directory Enumeration: Поддерживает пользовательские списки слов и расширения файлов для обнаружения скрытых каталогов и файлов.
Wayback MachineИзвлекает URL-адреса за последние пять лет для анализа изменений на веб-сайте и потенциальных уязвимостей.

Для начала вам нужно клонировать FinalReconрепозиторий с GitHub, используя команду `git git clone https://github.com/thewhiteh4t/FinalRecon.gitclone`. Это создаст новую директорию с именем "FinalRecon", содержащую все необходимые файлы.

Далее перейдите в только что созданную директорию с помощью команды cd FinalRecon`.`. После этого установите необходимые зависимости Python с помощью команды pip3 install -r requirements.txt`.`. Это гарантирует, что FinalReconв директории будут установлены все необходимые библиотеки и модули для корректной работы.

Чтобы основной скрипт был исполняемым, вам потребуется изменить права доступа к файлу с помощью команды chmod +x ./finalrecon.py`.`. Это позволит вам запускать скрипт непосредственно из терминала.

Наконец, вы можете убедиться в FinalReconправильности установки и получить обзор доступных параметров, запустив команду ./finalrecon.py --help.









Например, если мы хотим FinalReconсобрать информацию из заголовка и выполнить поиск Whois для inlanefreight.com, мы будем использовать соответствующие флаги ( --headersи --whois), поэтому команда будет выглядеть так:
