Вот несколько распространенных примеров Google Dorks; для получения дополнительных примеров обратитесь к базе данных Google Hacking Database :

Поиск страниц авторизации:
site:example.com inurl:login
site:example.com (inurl:login OR inurl:admin)
Выявление файлов, находящихся под угрозой:
site:example.com filetype:pdf
site:example.com (filetype:xls OR filetype:docx)
Раскрытие файлов конфигурации:
site:example.com inurl:config.php
site:example.com (ext:conf OR ext:cnf)(Поиск расширений, часто используемых для конфигурационных файлов)
Поиск резервных копий базы данных:
site:example.com inurl:backup
site:example.com filetype:sql















+---------------+-------------------------------------------------------------+-------------------------------------------+-------------------------------------------------------------+
| Оператор      | Описание оператора                                          | Пример                                    | Описание примера                                            |
+---------------+-------------------------------------------------------------+-------------------------------------------+-------------------------------------------------------------+
| site:         | Ограничивает поиск определённым сайтом или доменом          | site:example.com                          | Все страницы на сайте example.com                           |
| inurl:        | Ищет термин в URL-адресе                                    | inurl:login                               | Страницы с "login" в URL                                    |
| filetype:     | Поиск файлов определённого типа                             | filetype:pdf                              | PDF-файлы                                                   |
| intitle:      | Ищет термин в заголовке страницы                            | intitle:"confidential report"             | Страницы с "confidential report" в заголовке                |
| intext:       | Ищет термин в тексте страницы                               | intext:"password reset"                   | Страницы, содержащие "password reset" в тексте              |
| cache:        | Показывает кэшированную версию страницы                     | cache:example.com                         | Просмотр кэшированной версии сайта                          |
| link:         | Находит страницы, ссылающиеся на указанный URL              | link:example.com                          | Сайты, которые ссылаются на example.com                     |
| related:      | Находит похожие сайты                                       | related:example.com                       | Сайты, похожие на example.com                               |
| info:         | Краткая информация о сайте                                  | info:example.com                          | Основные сведения о сайте                                   |
| define:       | Определение слова или фразы                                 | define:phishing                           | Определение термина "phishing"                              |
| numrange:     | Поиск чисел в заданном диапазоне                            | numrange:1000-2000                        | Числа от 1000 до 2000                                       |
| allintext:    | Все слова должны быть в тексте страницы                     | allintext:admin password                  | Страницы, где есть и "admin", и "password"                  |
| allinurl:     | Все слова должны быть в URL                                 | allinurl:admin panel                      | URL содержит и "admin", и "panel"                           |
| allintitle:   | Все слова должны быть в заголовке                           | allintitle:confidential report 2023       | Заголовок содержит все указанные слова                      |
| AND           | Обязательное наличие всех терминов                          | site:example.com AND inurl:admin          | Только страницы с "admin" в URL на example.com              |
| OR            | Хотя бы один из терминов                                    | "linux" OR "ubuntu"                       | Страницы с упоминанием Linux или Ubuntu                     |
| NOT           | Исключает термин из результатов                             | site:bank.com NOT inurl:login             | Страницы на bank.com, кроме login                           |
| *             | Подстановочный знак (любой текст)                           | user* manual                              | "user manual", "users manual" и т.д.                        |
| ..            | Поиск в числовом диапазоне                                  | price 100..500                            | Цена от 100 до 500                                          |
| " "           | Точный поиск фразы                                          | "information security policy"             | Точное совпадение фразы                                     |
| -             | Исключает термин                                            | site:news.com -inurl:sports               | Исключает страницы со словом sports в URL                   |
+---------------+-------------------------------------------------------------+-------------------------------------------+-------------------------------------------------------------+
