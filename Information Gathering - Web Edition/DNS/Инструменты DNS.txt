┌─────────────────────────────────────┬───────────────────────────────────────────────────────────────────────────────────────────────┐
│ Команда                             │ Описание                                                                                      │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com                      │ По умолчанию запрашивает запись A (IPv4-адрес)                                                │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com A                    │ Явно запрашивает запись A — IPv4-адрес домена                                                 │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com AAAA                 │ Запрашивает запись AAAA — IPv6-адрес домена                                                   │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com MX                   │ Находит все MX-записи (почтовые серверы и их приоритеты)                                      │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com NS                   │ Показывает авторитетные серверы имён (NS-записи) для домена                                   │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com TXT                  │ Извлекает все TXT-записи (SPF, DKIM, DMARC, верификация и т.д.)                               │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com CNAME                │ Показывает CNAME-записи (алиасы), если они есть для указанного имени                          │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com SOA                  │ Выводит запись SOA: первичный NS, email админа, serial, таймеры зоны                          │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig @1.1.1.1 domain.com             │ Выполняет запрос через конкретный DNS-сервер (здесь Cloudflare 1.1.1.1) вместо системного     │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig +trace domain.com               │ Показывает пошаговый путь разрешения от корневых серверов до авторитетного (очень полезно)    │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig -x 192.168.1.1                  │ Обратный запрос (reverse DNS, PTR): IP → имя хоста                                            │
│ dig -x 192.168.1.1 @8.8.8.8         │ (часто нужно указать сервер, т.к. обратные зоны делегированы отдельно)                        │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig +short domain.com               │ Только чистый ответ без заголовков и статистики (идеально для скриптов)                       │
│ dig +short domain.com MX            │ Пример: выводит только имена и приоритеты MX-серверов                                         │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig +noall +answer domain.com       │ Отключает все секции кроме ANSWER (только полезный ответ)                                     │
│ dig +noall +answer +stats domain.com│ Можно комбинировать: ответ + статистика, без вопросов и авторитетных секций                   │
├─────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────┤
│ dig domain.com ANY                  │ Запрашивает ВСЕ типы записей сразу                                                            │
│                                     │ Примечание: многие современные серверы блокируют ANY-запросы (RFC 8482), возвращают пусто   │
│                                     │ или только часть записей                                                                      │
└─────────────────────────────────────┴───────────────────────────────────────────────────────────────────────────────────────────────┘

  1 Заголовок

;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 16449Эта строка указывает тип запроса ( QUERY), статус успешного выполнения ( NOERROR) и уникальный идентификатор ( 16449) для данного конкретного запроса.

;; flags: qr rd ad; QUERY: 1, ANSWER: 1, AUTHORITY: 0, ADDITIONAL: 0Это описание флагов в заголовке DNS:
qrФлаг ответа на запрос — указывает, что это ответ.
rdФлаг "Recursion Desired" означает, что была запрошена рекурсия.
adФлаг «Подлинные данные» означает, что средство разрешения считает данные подлинными.
Остальные числа указывают количество записей в каждом разделе DNS-ответа: 1 вопрос, 1 ответ, 0 авторитетных записей и 0 дополнительных записей.
;; WARNING: recursion requested but not availableЭто означает, что была запрошена рекурсия, но сервер её не поддерживает.

     
   
  2 Раздел вопросов

;google.com. IN AЭта строка уточняет вопрос: «Для чего предназначен IPv4-адрес (запись A) google.com?»
 


  3 Раздел ответов

google.com. 0 IN A 142.251.47.142Это ответ на запрос. Он указывает, что связанный с google.comним IP-адрес — 142.251.47.142. Символ ' 0' обозначает TTLвремя жизни (time-to-live), показывая, как долго результат может храниться в кэше до обновления.
 


  4 Нижний колонтитул

;; Query time: 0 msecЗдесь показано время, затраченное на обработку запроса и получение ответа (0 миллисекунд).

;; SERVER: 172.23.176.1#53(172.23.176.1) (UDP): Это позволяет определить DNS-сервер, предоставивший ответ, и используемый протокол (UDP).

;; WHEN: Thu Jun 13 10:45:58 SAST 2024Это отметка времени, когда был сделан запрос.

;; MSG SIZE rcvd: 54Это указывает на размер полученного DNS-сообщения (54 байта).
