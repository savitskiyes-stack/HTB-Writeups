Microsoft SQL ( MSSQL MSSQL) — это реляционная система управления базами данных от Microsoft отличается закрытам исходным кодом


Для доступа к базе данных, работающей на MSSQL, можно использовать множество других клиентов, включая, помимо прочих:

mssql-cli	SQL Server PowerShell	HeidiSQL	SQLPro	mssqlclient.py от Impacket







 Чтобы узнать, находится ли клиент на нашем хосте и где именно, можно использовать следующую команду

Конфигурация по умолчанию
Когда администратор впервые устанавливает и настраивает MSSQL для доступа по сети, служба SQL, скорее всего, будет работать от имени пользователя NT SERVICE\MSSQLSERVER

Подключение со стороны клиента возможно с помощью аутентификации Windows, и по умолчанию шифрование при попытке подключения не применяется.


+----------------------------------------------------+-----------------------------------------------------------------------------------+
| Уязвимость                                         | Описание / Риск                                                                   |
+----------------------------------------------------+-----------------------------------------------------------------------------------+
| Клиенты MSSQL не используют шифрование             | Подключение происходит по открытому каналу (plaintext). Перехват трафика (MITM)  |
|                                                    | позволяет легко получить логины, пароли, запросы и данные                         |
+----------------------------------------------------+-----------------------------------------------------------------------------------+
| Использование самоподписанных сертификатов         | Сертификат можно подделать (man-in-the-middle атака). Клиент может принять       |
| при шифровании                                     | фальшивый сертификат, если не проверяет цепочку доверия или не использует         |
|                                                    | Force Encryption + Trust Server Certificate = false                              |
+----------------------------------------------------+-----------------------------------------------------------------------------------+
| Использование именованных пайпов (named pipes)     | По умолчанию доступны через SMB (\\server\pipe\sql\query). Атакующий может       |
|                                                    | подключиться к пайпу без аутентификации по сети, если права SMB позволяют         |
+----------------------------------------------------+-----------------------------------------------------------------------------------+
| Слабые / стандартные учетные данные sa             | Учетная запись sa включена по умолчанию с простым паролем или без пароля.        |
|                                                    | Администраторы часто забывают её отключить или сменить пароль → полный доступ    |
+----------------------------------------------------+-----------------------------------------------------------------------------------+

Подключение с помощью Mssqlclient.py

Аутентификация в MSSQL позволит нам напрямую взаимодействовать с базами данных через механизм баз данных SQL
