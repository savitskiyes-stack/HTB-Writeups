Rsync
Rsync — это быстрый и эффективный инструмент для локального и удалённого копирования файлов. Он может использоваться для копирования файлов локально на заданном компьютере, а также на/с удалённых хостов. Он очень универсален и известен своим алгоритмом дельта-передачи. Этот алгоритм уменьшает объём данных, передаваемых по сети, если версия файла уже существует на целевом хосте. Он делает это, отправляя только различия между исходными файлами и более старой версией файлов, находящейся на целевом сервере. Он часто используется для резервного копирования и зеркалирования. Он находит файлы, которые необходимо передать, анализируя файлы, размер которых изменился, или время последнего изменения. По умолчанию он использует порт 873и может быть настроен на использование SSH для безопасной передачи файлов, используя установленное SSH-соединение с сервером.

R-Services
R-сервисы — это набор сервисов, предназначенных для обеспечения удалённого доступа или выполнения команд между хостами Unix по протоколу TCP/IP

R-servicesОни охватывают порты 512, 513, и 514и доступны только через набор программ, известных как r-commands


Пакет команд R состоит из следующих программ:

rcp ( remote copy)
рексек ( remote execution)
рлогин ( remote login)
рш ( remote shell)
рстат
время разрыва
рво ( remote who)



Команда  Сервисный демон  Порт  Транспортный протокол  Описание
-------  ----------------  ----  ----------------------  -------------------------------------------------------------------------------------
rcp      rshd              514   TCP                     Копирование файла/каталога в обоих направлениях. Аналог cp, но без предупреждения об перезаписи
rsh      rshd              514   TCP                     Открывает shell на удалённой машине без логина. Проверяет /etc/hosts.equiv и ~/.rhosts
rexec    rexecd            512   TCP                     Выполнение команд на удалённой машине с username/password через незашифрованный сокет
rlogin   rlogind           513   TCP                     Удалённый логин, аналог telnet, только для Unix-подобных хостов. Проверяет /etc/hosts.equiv и .rhosts







Файл /etc/hosts.equiv содержит список доверенных хостов и используется для предоставления доступа другим системам в сети
