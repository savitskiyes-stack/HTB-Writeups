Загрузка PowerShell из Интернета



PowerShell предлагает множество вариантов передачи файлов. В любой версии PowerShell для загрузки файла через HTTP, HTTPSили FTP. В следующей таблице описаны методы WebClient для загрузки данных из ресурса:



+--------------------+------------------------------------------------------------------+
| Метод              | Описание                                                         |
+--------------------+------------------------------------------------------------------+
| OpenRead           | Возвращает данные из ресурса в виде потока (Stream)              |
| OpenReadAsync      | Возвращает данные из ресурса в виде потока, не блокируя поток    |
| DownloadData       | Загружает данные из ресурса и возвращает массив байтов (byte[])  |
| DownloadDataAsync  | Загружает данные из ресурса и возвращает byte[], не блокируя поток |
| DownloadFile       | Загружает данные из ресурса в локальный файл                     |
| DownloadFileAsync  | Загружает данные из ресурса в локальный файл, не блокируя поток  |
| DownloadString     | Загружает данные из ресурса и возвращает строку (string)         |
| DownloadStringAsync| Загружает данные из ресурса и возвращает строку, не блокируя поток |
+--------------------+------------------------------------------------------------------+
