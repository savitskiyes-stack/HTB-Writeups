+----------+-----------------------------------------------+------------------------------------------+-------------------+-----------------------------------------------+
| Протокол | Полное название                               | Основная задача                                  | Порт по умолчанию | Пример использования                          |
+----------+-----------------------------------------------+------------------------------------------+-------------------+-----------------------------------------------+
| SMTP     | Simple Mail Transfer Protocol                 | Отправка писем (от клиента к серверу и между серверами) | 25, 465, 587      | Отправка email из Outlook/Gmail               |
| IMAP     | Internet Message Access Protocol              | Получение и синхронизация почты с сервера      | 143 (993 с SSL)   | Почта на нескольких устройствах               |
| POP3     | Post Office Protocol version 3                | Скачивание почты с сервера на устройство       | 110 (995 с SSL)   | Скачивание всей почты на один компьютер       |
| SNMP     | Simple Network Management Protocol            | Мониторинг и управление сетевыми устройствами  | 161 (UDP), 162    | Сбор метрик роутеров, свитчей, принтеров      |
| SNTP     | Simple Network Time Protocol                  | Упрощённая синхронизация времени               | 123 (UDP)         | Установка точного времени на устройствах     |
| SMB      | Server Message Block                          | Общий доступ к файлам, принтерам, сетевым ресурсам | 445 (TCP), 139    | Общие папки в Windows, Samba в Linux          |
| MySQL    | MySQL Database Protocol                       | Доступ к реляционной базе данных MySQL/MariaDB | 3306 (TCP)        | Подключение к веб-приложениям, CMS, аналитика |
| MSSQL    | Microsoft SQL Server Protocol                 | Доступ к базе данных Microsoft SQL Server      | 1433 (TCP)        | Корпоративные приложения, .NET, Power BI      |
| Oracle TNS | Transparent Network Substrate (Oracle Net)  | Подключение к базам Oracle Database            | 1521 (TCP)        | Enterprise-системы, банки, ERP                |
| IPMI     | Intelligent Platform Management Interface     | Удалённое управление сервером (вне ОС)         | 623 (UDP)         | BMC, iLO, DRAC, удалённый доступ к BIOS/серверу |
+----------+-----------------------------------------------+------------------------------------------+-------------------+-----------------------------------------------+
